Glossary

Metadata
Names, ownership and status describing a file; separate from its bytes.
Object storage
Stores file bytes under opaque keys through an S3-compatible API.
Assertion
Hub's signed, short-lived statement of actor, workspace, scope and request.
Receipt
Rodrigo's durable record that makes an action retry safe.
Change stream
Database change notifications used to refresh reads; not the product event bus.
Scrape
Prometheus periodically requests a metrics endpoint.
GPU inference
Model computation on a server GPU; separate from browser WebGPU.
