How to use these links

For runtime changes, start with the behavior tree and keep its HTML version aligned. For data shapes and scopes, use the durable data contract and Rodrigo's authoritative contract. For contributor rules, read root AGENTS.md and the agent guide.

This atlas deliberately omits endpoint inventories, configuration values, per-app controls, and proposed feature details. Those belong in the linked focused guides.
